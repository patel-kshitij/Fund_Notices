# fund-notices

Work in progress. This tool reads synthetic fund notice PDFs, sorts them by type, pulls out the key fields, and flags doubtful ones for a person to review. The whole pipeline is meant to run on a laptop, and no document leaves the machine.

Results and run instructions will be added once the evaluate command exists.
